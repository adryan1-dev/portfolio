# Adryan Chaves Portfolio

Crie uma landing page de portfólio profissional, moderna e premium para Adryan Chaves, desenvolvedor Full Stack / Software Engineer.

Objetivo

A página deve funcionar como um portfólio pessoal para apresentar rapidamente quem sou, minhas principais tecnologias, meus projetos e formas de contato. O design deve transmitir tecnologia, profissionalismo, criatividade e domínio técnico, evitando aparência de template genérico.

Estilo visual

Design moderno, minimalista e sofisticado.

Dark mode como padrão.

Fundo predominantemente escuro, com contraste elevado.

Usar uma cor de destaque relacionada à tecnologia, como azul elétrico, roxo ou ciano.

Tipografia moderna e limpa.

Microinterações e animações sutis ao passar o mouse e durante o scroll.

Cards com bordas sutis, glassmorphism discreto e sombras suaves.

Layout totalmente responsivo para desktop, tablet e mobile.

Priorizar excelente hierarquia visual e espaçamento.

Evitar excesso de elementos, gradientes exagerados ou aparência de site gerado por IA.

1. HERO / APRESENTAÇÃO

Criar uma seção inicial impactante ocupando boa parte da primeira tela.

No lado esquerdo:

Pequeno texto de identificação: "Olá, eu sou"

Nome em destaque: Adryan Chaves

Título profissional: Full Stack Developer

Texto curto apresentando meu perfil, com foco em desenvolvimento de aplicações web modernas, interfaces e soluções completas.

Botão principal e bastante destacado: "Baixar CV", com ícone de download.

Botão secundário: "Ver projetos", que leva para a seção de projetos.

No lado direito:

Inserir uma área para minha foto profissional, com formato moderno e destaque visual.

A foto deve ter aparência integrada ao design, podendo utilizar borda, glow ou elemento gráfico sutil ao redor.

Não distorcer a imagem.

Abaixo ou próximo da apresentação, criar uma faixa com as principais tecnologias que utilizo, exibindo ícones oficiais das tecnologias:

HTML5

CSS3

JavaScript

React

Node.js

Express.js

Python

PostgreSQL

Git

GitHub

Docker

Os ícones devem ser visualmente consistentes e organizados, com tooltip contendo o nome da tecnologia ao passar o mouse.

2. PROJETOS

Criar uma seção chamada "Projetos em destaque".

Os projetos devem aparecer em um carrossel horizontal moderno, com cards grandes e visualmente atrativos.

Cada card deve conter:

Imagem/capa do projeto

Nome do projeto

Descrição curta

Tecnologias utilizadas

Botão/link para "Ver projeto"

Botão/link para "GitHub"

O carrossel deve:

Possuir navegação por setas.

Ter indicadores de posição.

Funcionar perfeitamente no mobile através de swipe.

Possuir animações suaves.

Destacar visualmente o projeto atualmente selecionado.

Criar inicialmente alguns projetos fictícios/placeholder com estrutura pronta para que eu possa substituir posteriormente pelas informações reais.

3. CONTATO

Na última seção, criar uma área de contato simples e elegante.

Título:
"Vamos construir algo juntos?"

Texto curto incentivando o visitante a entrar em contato.

Exibir os contatos como ícones grandes e interativos, cada um com hover animation:

Email

GitHub

LinkedIn

WhatsApp

Cada ícone deve ser clicável e abrir o destino correspondente.

Adicionar também uma pequena mensagem indicando disponibilidade para oportunidades profissionais, projetos e colaborações.

FOOTER

Criar um footer minimalista contendo:

© 2026 Adryan Chaves. Todos os direitos reservados.

E os mesmos ícones de contato de forma compacta.

Requisitos técnicos

Construir com React.

Código organizado e componentizado.

Criar componentes reutilizáveis para Hero, TechStack, ProjectsCarousel, Contact e Footer.

Utilizar boas práticas de responsividade.

Garantir acessibilidade básica.

Utilizar ícones profissionais, preferencialmente Lucide Icons e/ou Simple Icons.

Não utilizar emojis como ícones.

Criar estados de hover, focus e active.

Animações devem ser sutis e profissionais.

O botão de download do CV deve estar preparado para receber posteriormente o arquivo PDF.

Os links de GitHub, LinkedIn, WhatsApp e Email devem ficar centralizados em um único local/configuração para facilitar futuras alterações.

Criar estrutura preparada para substituir facilmente minha foto, CV, projetos e links.

Não adicionar seções desnecessárias como "Minha jornada", "Depoimentos" ou "Serviços".

O foco deve ser eu + tecnologias + projetos + contato.

Experiência desejada

Ao entrar no site, o visitante deve entender em poucos segundos:

Quem é Adryan.

Que ele é desenvolvedor Full Stack.

Quais tecnologias domina.

Quais projetos já desenvolveu.

Como entrar em contato.

O resultado final deve parecer um portfólio de desenvolvedor profissional de alto nível, adequado para apresentar a recrutadores e empresas de tecnologia.
